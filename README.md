# Portafolio BOCA.

Archivos:
- `index.html`: página principal (casos, recorrido, contacto). El contenido se edita en los bloques `SITE` y `PROJECTS` al final del archivo.
- `casos.html`: páginas de caso (MaesPro, BIG Academy). Busca las cajas "Por completar".
- `fx.js`: efectos interactivos. `PANEL = true` muestra la caja de pruebas; ponlo en `false` al publicar.
- `img/`: imágenes (WebP o JPG, menos de 200 KB cada una).

Para actualizar: en GitHub, abre el archivo, pulsa el lápiz, edita y pulsa "Commit changes". En 1 o 2 minutos se ve el cambio.

Antes de compartir el enlace con reclutadores: quita la línea `noindex` de `index.html` y `casos.html`, y pon `PANEL = false` en `fx.js`.
